# Fuel Tracker

App Android per il tracciamento dei rifornimenti di carburante, con supporto multi-veicolo, grafici e statistiche.

## Tecnologie
- Kotlin + Android Views (XML), Material Design 3
- Room Database
- MVVM + LiveData
- MPAndroidChart
- GitHub Actions per la build automatica

## Build automatica
Push su `main` -> tab **Actions** -> ultimo run verde -> **Artifacts** -> `app-debug.apk`.

## Requisiti
- Android 8.0 (API 26)+
- Testato su Samsung A52 / Android 14
